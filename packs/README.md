# Structure packs

Drop structure packs here (a `*.py` file or a package directory with
`__init__.py`). Flux Studio loads them at start-up and adds their models to the
Layout tab. You can also list pack files or folders in `FLUX_PACKS`.

Everything in this folder except this README is ignored by git, so private
packs stay out of the repository. See `docs/STRUCTURE_PACKS.md`.
